# Financial Data App

Author: Christopher Robles

## DESCRIPTION

This is a React-based application that fetches and displays financial data for Apple Inc. using the Financial Modeling Prep API. Users can filter and analyze key financial metrics, such as revenue, net income, and gross profit.

## Instructions to run the app locally:

Ensure you have the following installed on your system:
Node.js (v16 or higher)
npm (Node Package Manager)

Step 1:
Clone the repository:
git clone https://github.com/Robles54/Financial_Data_App.git
cd Financial_Data_App

Step 2:
Install Dependencies:
npm install

Step 3:
Run the Development Server
Start the application with:
npm start

This will start the development server and open the app in your default browser at http://localhost:3000.

## Features

Fetches annual financial data for Apple Inc.

Displays data in a sortable and filterable table.

Allows filtering by date range, revenue range, and net income range.

Mobile-friendly design using TailwindCSS.

## Scripts

npm start: Runs the app in development mode.

npm run build: Builds the app for production.

npm run deploy: Deploys the app to GitHub Pages.
